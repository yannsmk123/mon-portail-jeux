🎮 Ouvrir le jeu ↗

Les jeux classiques HTML fonctionnent directement ; ceux avec un serveur Node.js demandent une intégration particulière. La mise en ligne passe par GitHub puis Render. Cela peut redémarrer ton portail : publie plutôt entre deux parties. Les jeux déjà présents ne seront pas remplacés.

🔧 Activer l'ajout automatique (une seule fois)

Ton portail sait déjà ajouter des jeux. Il faut simplement relier son formulaire à ton dépôt GitHub en configurant trois paramètres dans Render. Ensuite, tu ajouteras tes jeux depuis cette fenêtre, sans retourner sur GitHub.

  1. Sur GitHub, crée un jeton ayant l'autorisation Contents: Read and write sur le dépôt du portail.
  2. Sur Render, ouvre ton service mon-portail-jeux → Environment.
  3. Ajoute ADMIN_PASSWORD (un mot de passe personnel), GITHUB_REPOSITORY (propriétaire/nom-du-dépôt), GITHUB_TOKEN (le jeton GitHub). Sauvegarde.
  4. Après le redéploiement, actualise le site et utilise Ajouter un jeu.

Ne colle jamais ton jeton GitHub dans une conversation ou dans un fichier public. Il doit rester uniquement dans les variables d'environnement Render.
