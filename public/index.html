Ajouter un jeu

Choisis un fichier HTML ou un ZIP contenant index.html et ses images, sons ou scripts. Il sera proposé à tes amis depuis ce portail.

Après l'ajout, l'hébergement republie automatiquement le portail. Une partie en cours peut être interrompue pendant ce redéploiement : ajoute tes jeux entre deux parties.

Ajout sans code, depuis GitHub

Pour ajouter un jeu, ouvre le dossier uploads de ton dépôt GitHub, clique sur Add file → Upload files, glisse le ZIP ou HTML, puis valide. Render actualisera automatiquement le site.

Ouvrir GitHub ↗

Pour ajouter directement depuis cette fenêtre, configure une fois ADMIN_PASSWORD, GITHUB_REPOSITORY et GITHUB_TOKEN dans Render. Voir le guide fourni.
